# Candidatos a configuración de entorno

Revisión de API, web y mobile tras externalizar el destino provisional de CU10. Los valores de esta lista se identificaron para evaluación; no se modificaron ni se agregaron variables para ellos.

| Ubicación                                                                                                      | Valor actual                                    | Motivo para considerar configuración                                                                                                                                   |
| -------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `api/src/infra/postgres.ts`                                                                                    | Conexión: 5.000 ms; consulta: 10.000 ms         | Ajustar tolerancia a latencia de PostgreSQL local y remoto.                                                                                                            |
| `api/src/infra/redis.ts`                                                                                       | Comando: 3.000 ms; un reintento por solicitud   | Ajustar tiempos y reintentos a Redis local o remoto, conservando fallas acotadas.                                                                                      |
| `api/src/infra/oauth.ts`                                                                                       | Verificación de Google: 10.000 ms               | Ajustar tiempo de espera del proveedor de autenticación.                                                                                                               |
| `FaltaUno-Web/src/api/cliente.ts` y `FaltaUno-Mobile/src/api/cliente.ts`                                       | Solicitudes a la API: 15.000 ms                 | Ajustar por entorno y coordinar con los tiempos del backend.                                                                                                           |
| `api/src/app.ts`                                                                                               | Cuerpo JSON: `100kb`; `trust proxy`: 1 salto    | Dependen de límites operativos y topología real del despliegue. La confianza en proxies requiere revisar la infraestructura antes de cambiarla.                        |
| `api/src/infra/logger.ts`                                                                                      | Nivel `info`, o `silent` en pruebas             | Permitir distinta verbosidad de diagnóstico por entorno.                                                                                                               |
| `FaltaUno-Web/src/componentes/SelectorUbicacion.tsx` y `FaltaUno-Mobile/src/componentes/SelectorUbicacion.tsx` | Espera: 500 ms; mínimo: 3 caracteres            | Son parámetros de interacción y consumo del proveedor. El mínimo también existe en `api/src/modulos/actividades/actividades.dto.ts`; habría que coordinar el contrato. |
| `FaltaUno-Mobile/src/api/cliente.ts`                                                                           | Puerto de API autodetectada en desarrollo: 3000 | Útil si el equipo utiliza otros puertos; hoy se puede reemplazar toda la URL con `EXPO_PUBLIC_URL_API`.                                                                |

Las rutas `FaltaUno-Web/` y `FaltaUno-Mobile/` corresponden a repositorios hermanos.

Los límites de columnas SQL, códigos HTTP, identificadores de protocolo, textos de interfaz y reglas del dominio no se consideran automáticamente variables de entorno. La zona horaria de Uruguay y la restricción de ubicaciones a Uruguay corresponden al alcance actual del producto; hacerlas configurables requeriría una decisión funcional y coordinación entre clientes y API.
